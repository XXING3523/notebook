
《代数的历史：人类对未知量的不舍追踪》, John Derbyshire著, 冯速 译. 

数列 $\{a_n\}$ 收敛于 $A$ 的标准定义是：
$\forall \varepsilon > 0, \exists N \in \mathbb{N}^*, \text{当 } n > N \text{ 时, 恒有 } |a_n - A| < \varepsilon$。

#### 选项 1：固定 $\varepsilon$ 的陷阱
> **命题：** 若对于**任意给定的正数** $\varepsilon$，存在正整数 $n_0$，使得 $|a_{n_0} - A| < \varepsilon$ 成立，则 $\lim\limits_{n \to \infty} a_n = A$。
> *   **迷惑点：** 看起来很像定义，但它只要求**某一个**项 $n_0$ 靠近 $A$。
> *   **真相：** **假命题。** 例如 $a_n = \sin(n)$。对于任何 $\varepsilon$，你总能找到某个项离 0 很近，但数列整体并不收敛。定义要求的是“从某项开始的**所有项**”都要靠近。

#### 选项 2：量词顺序的调换（经典的超强限制）
> **命题：** 若存在正整数 $N$，使得对于**任意正数** $\varepsilon$，都有当 $n > N$ 时 $|a_n - A| < \varepsilon$ 成立，则 $\lim\limits_{n \to \infty} a_n = A$。
> *   **迷惑点：** 只是把 $\forall \varepsilon$ 和 $\exists N$ 换了位置。
> *   **真相：** **真命题（但条件极其苛刻）。** 这个条件实际上意味着从第 $N+1$ 项开始，$a_n$ 必须**严格等于** $A$（参考前文 $A=6$ 的推导）。它符合极限定义，但它描述的是“常数数列”。

#### 选项 3：“无限多项”不代表“所有项”
> **命题：** 若对于任意正数 $\varepsilon$，满足 $|a_n - A| < \varepsilon$ 的项 $a_n$ 有**无穷多个**，则 $\lim\limits_{n \to \infty} a_n = A$。
> *   **迷惑点：** “无穷多个”听起来覆盖了数列的绝大部分。
> *   **真相：** **假命题。** 例如 $a_n = 0, 1, 0, 1, 0, 1 \dots$。满足 $|a_n - 0| < \varepsilon$ 的项有无穷多个（所有的偶数项），但数列并不收敛。

### 第二组：函数单调性与连续性的逻辑变体

#### 选项 4：单点趋势 vs 全局单调
> **命题：** 若函数 $f(x)$ 定义在 $\mathbb{R}$ 上，且对于任意 $x_0 \in \mathbb{R}$，都存在 $\delta > 0$，使得当 $x \in (x_0, x_0 + \delta)$ 时恒有 $f(x) > f(x_0)$，则 $f(x)$ 在 $\mathbb{R}$ 上严格单调递增。
>
> *   **迷惑点：** 这句话说的是“在任一点向右看去，近处的一段都比该点高”。
> *   **真相：** **假命题。** 如果函数不连续，这完全可能失效。你可以构造一个在每个整数点由于跳跃而“看起来在升”，但在区间内部却在“猛降”的函数。
> *   **数理拓展：** 如果增加一个条件“$f(x)$ 是**连续函数**”，那么这个命题就变成了**真命题**（这涉及拓扑学中的覆盖性质）。

#### 选项 5：稠密性陷阱（有理数与实数）
> **命题：** 若 $f(x)$ 在 $\mathbb{R}$ 上连续，且对于**任意两个有理数** $r_1 < r_2$，恒有 $f(r_1) < f(r_2)$，则 $f(x)$ 在 $\mathbb{R}$ 上严格单调递增。
> *   **迷惑点：** 只限制
> *   **真相：** **真命题。** 因为有理数在实数中是**稠密**的，通过极限过程可以将有理数的序关系保序地传递给实数。
> *   **变体：** 如果去掉“连续”这个前提，该选项立刻变成**假命题**（你可以让实数点在有理数点之间飞舞掉队）。



> **选项：** $f(x)$ 在 $\mathbb{R}$ 上连续，且对于任意 $x_1 < x_2$，恒有 $f(x_1) < f(\frac{x_1+x_2}{2}) < f(x_2)$。
> *   **解析：** **正确（充分性成立）**。
>   *   这个条件比单调性的定义要弱（只要求中点在中间），但实际上它配合连续性可以锁定全局。
>   *   通过不断取中点，你可以证明在任何区间内部的所有“二进分点”（形如 $\frac{k}{2^n}$ 的点）都符合单调关系。由于二进分点在实数集里是稠密的，结合连续性，函数必须是全局递增的。

**（多选）** 已知数列 $\{a_n\}$ 和常数 $A$，下列选项中能够推导出 $\lim\limits_{n \to \infty} a_n = A$ 的充分条件是：

(A) 对于任意给定的正整数 $k$，都存在正整数 $N$，使得当 $n > N$ 时，恒有 $|a_n - A| < \frac{1}{k}$。

(B) 存在正整数 $N$，使得对于任意的正数 $\varepsilon$，当 $n > N$ 时，恒有 $|a_n - A| < \varepsilon$。

(C) 对于任意给定的正数 $\varepsilon$，存在无穷多个正整数 $n$，使得 $|a_n - A| < \varepsilon$。

(D) 对于任意给定的正数 $\varepsilon$，满足 $|a_n - A| \geqslant \varepsilon$ 的项 $a_n$ 只有有限个。

(E) 数列 $\{a_n\}$ 满足 $|a_{n+1} - A| < |a_n - A|$，且对于任意 $n \in \mathbb{N}^*$ 均有 $a_n \neq A$。

**相关结论（等价定义）：**
$\lim\limits_{n \to \infty} a_n = A \iff$ 对任意给定的 $k \in \mathbb{N}^*$，存在 $N \in \mathbb{N}^*$ 使 $n > N$ 时 $|a_n - A| < \frac{1}{2^k}$。

**更进一步的陷阱：**
如果我们将 (A) 稍微改动：
> “对于任意确定的 $\varepsilon > 0$，存在**无数个** $N$，使得当 $n = N$ 时，满足 $|a_n - A| < \varepsilon$。”

这个命题是**错误**的。这只是说明 $A$ 是数列的一个**聚点（Limit Point）**，而不是极限。要成为极限，必须是对所有**后续**的 $n$ 产生“强制覆盖”。
