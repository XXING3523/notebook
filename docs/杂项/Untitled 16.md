这个定义可以表示为：
$$\forall \epsilon \, (\epsilon > 0 \to \exists \delta \, (\delta > 0 \wedge \forall x \, (|x - x_0| < \delta \to |f(x) - f(x_0)| < \epsilon)))$$

#### 2. 左右连续性（分段函数判定）
**结论**：函数在 $x_0$ 处连续 $\iff$ 它在该点既**左连续**又**右连续**。
即：$f(x_0^-) = f(x_0^+) = f(x_0)$。其中 $f(x_0^-) = \lim_{x \to x_0^-} f(x)$。
*这是判断分段函数在分界点是否连续的标准方法。*

#### 3. 海涅定理（Heine / 归结原则）
这是函数连续性与**数列极限**之间的桥梁。
**结论**：函数 $f(x)$ 在 $x_0$ 处连续 $\iff$ 对于任何收敛于 $x_0$ 的数列 $\{x_n\}$，相应的函数值数列 $\{f(x_n)\}$ 都收敛于 $f(x_0)$。
*这告诉我们：连续函数可以与极限符号交换顺序：$f(\lim x_n) = \lim f(x_n)$。*

### 结论 2：局部有界性 (Local Boundedness)
**命题**：若 $\lim_{x \to x_0} f(x) = A$，则在 $x_0$ 的某去心邻域内，$f(x)$ 是有界的。

**证明**：
1.  **选定特定的挑战值**：在定义中，$\epsilon$ 是任意的。我们取一个具体的 $\epsilon = 1$。
2.  **寻找对应的控制范围**：根据极限定义，存在 $\delta > 0$，使得当 $0 < |x - x_0| < \delta$ 时，有：
    $$|f(x) - A| < 1$$
3.  **利用三角不等式**：
    由 $|f(x)| = |f(x) - A + A|$，根据绝对值性质 $|a+b| \le |a| + |b|$，得：
    $$|f(x)| \le |f(x) - A| + |A| < 1 + |A|$$
4.  **结论**：取 $M = 1 + |A|$，则在这个 $\delta$ 邻域内，$|f(x)| \le M$。即函数在该局部是有界的。 $\Box$

### 1. 描述性定义（高中直观理解）
设函数 $f(x)$ 在点 $x_0$ 的某个去心邻域内有定义。如果当自变量 $x$ 无限趋近于 $x_0$（但 $x \neq x_0$）时，函数值 $f(x)$ 无限趋近于一个确定的常数 $A$，那么就说 $A$ 是函数 $f(x)$ 当 $x \to x_0$ 时的**极限**，记作：
$$\lim_{x \to x_0} f(x) = A$$

**逻辑符号表达（衔接命题逻辑）：**
$$\forall \epsilon > 0, \exists \delta > 0, \forall x (0 < |x - x_0| < \delta \implies |f(x) - A| < \epsilon)$$

证明“连续函数的局部保号性”是高中数学向大学数学分析（Mathematical Analysis）过渡的经典案例。这一证明不仅展示了从“直观描述”向“严谨逻辑”的转变，还深度融合了你参考资料中提到的**逻辑形式化**。

---

### 一、 前置知识要求（衔接关键点）

要向学生讲透这个证明，需要完成以下三个知识补丁的“安装”：

1.  **绝对值不等式的集合表达（高中基础）**：
    理解 $|f(x) - f(x_0)| < \epsilon$ 等价于 $f(x) \in (f(x_0) - \epsilon, f(x_0) + \epsilon)$。这是理解函数值“范围”的物理基础。
2.  **极限与连续的 $\epsilon-\delta$ 定义（大学核心）**：
    这是衔接的最难点。学生需要从高中的“$x$ 趋近于 $x_0$”转变为：
    $$\forall \epsilon > 0, \exists \delta > 0, \text{ 当 } |x - x_0| < \delta \text{ 时，有 } |f(x) - f(x_0)| < \epsilon$$
3.  **命题逻辑与量词（参考资料关联）**：
    参考资料强调了**自然语言的形式化**。保号性的证明本质上是利用形式化定义的“存在性”（$\exists \delta$）来推导结论。学生需要明白，证明“存在一个邻域”意味着必须找到（或证明存在）一个具体的 $\delta$。

### 二、 局部保号性的形式化证明

**定理（局部保号性）**：
设函数 $f(x)$ 在点 $x_0$ 连续，且 $f(x_0) > 0$。则存在 $\delta > 0$，使得当 $x \in (x_0 - \delta, x_0 + \delta)$ 时，$f(x) > 0$。

有这样一种说法：一个复杂的数学问题做不出来，多半是由于一个比问题A简单的问题B未做好。反过来说，简单的问题B做好了，那么，问题A的难度就会大大下降，甚至迎刃而解。

也就是说，当我们不具备“一步到位”的能力时，先考虑简单的情况，特殊的情况，要么将规模缩小寻找规律，要么先举出一个特例，再尝试据此猜想一般的情况并完成严谨的证明。诚然，想要把一个问题拆解成一连串弱化的子问题也并非易事。
