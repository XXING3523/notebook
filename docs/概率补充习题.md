\[
\delta = E(|X - \mu|).
\]

（1）设 $N = 2n$，$n$ 是正整数。

（ⅱ）证明：$\delta = \sum_{r=0}^{n-1} (n - r) \binom{2n}{r} \dfrac{1}{2^{2n-1}}$。
（ⅲ）证明：当 $r > 0$ 时，$r \binom{2n}{r} = 2n \binom{2n-1}{r-1}$，并证明 $\delta = \dfrac{n}{2^{2n}} \binom{2n}{n}$。

（2）对 $N = 2n + 1$，推导 $\delta$ 的类似表达式。

（1）证明：当 $1 \le r \le 2n$ 时，
\[
r \binom{2n}{r} = (2n + 1 - r) \binom{2n}{2n + 1 - r}.
\]

\[
\sum_{r=0}^{2n} r \binom{2n}{r} = 2\sum_{r=n+1}^{2n} r \binom{2n}{r}.
\]
