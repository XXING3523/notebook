二分查找（Binary Search）

Element Search

一个序列$A$满足$A_1>A_n$，找到任意一个下标$i$，使得$A_i>A_{i+1}$

**算法简述**

二分，若$A_{mid}>A_{mid+1}$，返回$mid$，否则考虑区间$[mid+1,R]$，时间复杂度为$O(\log n)$

中位数查找（Median Sreach）

输入两个排好序的数列$A[1,\cdots,n],B[1,\cdots,n]$，求$A\cup B$的中位数

方法一：

（A）假设中位数在$A$中。

（1）$L=1,R=n$

（2）While循环做二分查找：$L<R$

（3）$mid=(L+R)/2$

（4）$A[mid]$在$B$中的排名$\to r$

（5）若$(mid-1)+(r-1)<n-1$，则$L=mid+1$；否则$R=mid$

（6）循环结束后，返回$A[L]$

（B）假设中位数在$B$中，同理，总时间复杂度为$O(\log^2 n)$

优化方向一：比较部分可等价于$A[mid]<B[n-mid+1]$，时间复杂度降为$O(1)$；

优化方向二；注意到当$A[n/2]<B[n/2]$时，中位数不可能在$A[1,\cdots,n/2],B[n/2+1,\cdots,n]$中。

步骤：

（1）比较$A[n/2],B[n/2]$

（2）若小于，则对$A[n/2+1,\cdots,n],B[1,\cdots,n/2]$进行递归操作

（3）若大于，则对$A[1,\cdots,n/2],B[n/2+1,\cdots,n]$进行递归操作

当$A,B$区间均为1时，较小的为中位数。

时间复杂度为$O(\log n)$

1D Peak Finding

输出一个序列的任意一个局部最大值（输入序列保证存在局部最大值）

**算法简述**

对于区间$L\sim R$，取中点$mid=(L+R)/2$

若$mid$不在左端点且$A_{mid-1}>A_{mid}$，则$R\gets mid-1$;

若$mid$不在右端点且$A_{mid+1}>A_{mid}$，则$L\gets mid+1$；

否则，返回$A_{mid}$

2D Peak Finding

输出一个二维数阵的任意一个局部最大值（输入序列保证存在局部最大值）

方法一：用每一列的最大值代替这一列，压缩得到一行，对这一行使用1D Peak Finding算法即可，得到的行峰值即为数阵局部最大值。

时间复杂度为$O(n^2)+O(\log n)=O(n^2)$

方法二：设当前处理第$L\sim R$列，取$mid=(L+R)/2$，查找第$mid$列中的最大值$A_{mid,j}$，$A_{mid,j}$若是峰值，返回$A_{mid,j}$即可，否则，若$A_{mid,j}<A_{mid+1,j}$，则$L=mid+1$，若$A_{mid,j}<A_{mid-1,j}$，则$R=mid-1$

时间复杂度满足$T(n)=T(n/2)+O(n)=O(n\log n)$

方法三：按田字划分数阵，得到四个子数阵，查找田字划分线上的最大值$A_{i,j}$，其只可能与上下或左右两个方向的数没做比较，若其大于这两个方向的数，这个数就是峰值，否则，递归考虑比此数小的那个数所属的子数阵。

时间复杂度$T(n,n)\le T(n/2,n/2)+\Theta(n)=O(n)$

（注意：方法三与方法二在时间复杂度上的区别关键在$\Theta(n)$）
